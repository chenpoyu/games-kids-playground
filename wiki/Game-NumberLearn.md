# 🔢 數字學習 NumberLearn

> 三關式數字教學，從數數到排序循序漸進

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 3~6 歲 |
| 路徑 | `/number-learn` |
| 原始碼 | `src/games/NumberLearn/NumberLearn.jsx` |
| 學習目標 | 數數、數字認識、數字排序 |

## 關卡設計

本遊戲有 **3 個關卡**，每關 5 題：

### 第 1 關：認識 1~5（數一數）
- 畫面顯示若干個 emoji 物件（🍎🌟🐟 等）
- 數一數有幾個，從 4 個選項中選出正確數量
- 選對 → 進入下一題，選錯 → 搖晃提示可重試

### 第 2 關：認識 6~10（數一數）
- 與第 1 關相同玩法，但數字範圍提升至 6~10

### 第 3 關：數字排序 1~10（排序）
- 畫面顯示亂序的數字 1~10
- 按照 **從小到大** 的順序依序點擊
- 正確的數字會移至已排序區域

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 2 次 |
| ⭐ | 失誤 > 2 次 |

## 技術細節

- 「數一數」題型：隨機從該關範圍挑一個數字，隨機挑一個 emoji，生成對應數量
- 選項生成：正確答案 + 3 個鄰近的錯誤答案（從 `num ± 3` 範圍取值），隨機打亂
- 「排序」題型：將數字 1~10 隨機打亂，玩家需按順序點選
- 10 種 emoji 隨機輪替：🍎🌟🐟🦋🍒🌸🐣🎈🍬🧩
- 通過每關後可進入下一關，完成全部 3 關顯示最終過關畫面
