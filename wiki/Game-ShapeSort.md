# 🔷 形狀排排看 ShapeSort

> 認識基本形狀，將形狀放到正確的位置

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 3~6 歲 |
| 路徑 | `/shape-sort` |
| 原始碼 | `src/games/ShapeSort/ShapeSort.jsx` |
| 學習目標 | 形狀認識、圖形配對 |

## 遊戲規則

1. 畫面分為兩區：形狀按鈕區 與 目標位置區
2. 顯示 6 種形狀供選擇
3. 先點選一個形狀，再點選對應的目標位置
4. 配對正確則形狀歸位並顯示正確動畫
5. 配對錯誤則搖晃提示
6. 所有形狀歸位即過關

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 2 次 |
| ⭐ | 失誤 > 2 次 |

## 技術細節

- 6 種基本幾何形狀（圓形、正方形、三角形、星形等）
- 形狀使用 emoji 或 CSS 繪製
- 點選交互：先選「來源形狀」→ 再選「目標位置」→ 判定配對
- 已配對的形狀按鈕變為不可點擊狀態
