# 🦁 動物翻翻樂 AnimalPuzzle

> 翻翻卡片找出一樣的動物，培養觀察力和記憶力

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 2~5 歲 |
| 路徑 | `/animal-puzzle` |
| 原始碼 | `src/games/AnimalPuzzle/AnimalPuzzle.jsx` |
| 學習目標 | 記憶力、觀察力、動物認識 |

## 遊戲規則

1. 畫面上顯示多張倒蓋的動物卡片
2. 點擊卡片翻開，看到動物 emoji
3. 翻開第二張，若動物相同則配對成功
4. 不相同則兩張卡片自動蓋回
5. 找出所有動物配對即過關

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 3 次 |
| ⭐ | 失誤 > 3 次 |

## 技術細節

- 使用 emoji 動物圖示，無需載入圖片資源
- 卡片隨機打亂排列
- 翻牌動畫使用 CSS `rotateY` 3D 翻轉效果
- 配對判定：比較兩張卡的 emoji 值是否相同
