# 🔤 ABC 英文字母 ABCLearn

> 認識 26 個字母，學習字母配對和排序

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 4~6 歲 |
| 路徑 | `/abc-learn` |
| 原始碼 | `src/games/ABCLearn/ABCLearn.jsx` |
| 學習目標 | 字母認識、大小寫配對、字母排序 |

## 遊戲模式

本遊戲包含 **3 種模式**：

### 🔤 模式一：字母學習
- 顯示一個大寫字母，搭配對應的 emoji 提示（如 A → 🍎 Apple）
- 從 4 個選項中找出正確的大寫字母
- 每輪 8 題

### 🔗 模式二：大小寫配對
- 顯示一個大寫字母
- 從多個小寫字母選項中找出對應的小寫
- 訓練大小寫字母的對應關係

### 📊 模式三：字母排序
- 顯示亂序的字母序列
- 按照 A → B → C... 的正確順序依序點選

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 2 次 |
| ⭐ | 失誤 > 2 次 |

## 技術細節

- 26 個字母各搭配一個代表性 emoji 與英文單字
- 選項生成使用隨機打亂，避免正確答案固定在同一位置
- 三種模式共用同一個元件，透過 `type` state 切換
- 字母排序模式的已排序字母會移至上方展示區
