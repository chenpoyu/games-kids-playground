# 🚀 快速開始

## 環境需求

- **Node.js** 18 以上（建議 20 LTS）
- **npm** 9 以上

## 安裝步驟

```bash
# 1. 克隆專案
git clone https://github.com/chenpoyu/games-kids-playground.git
cd games-kids-playground

# 2. 安裝依賴
npm install

# 3. 啟動開發伺服器
npm run dev
```

開啟瀏覽器前往 `http://localhost:5173/games-kids-playground/`

## 常用指令

| 指令 | 說明 |
|------|------|
| `npm run dev` | 啟動開發伺服器（支援 HMR） |
| `npm run build` | 建構正式版本至 `dist/` |
| `npm run preview` | 在本地預覽正式版本 |
| `npm run lint` | ESLint 程式碼檢查 |
| `npm test` | Vitest 監聽模式 |
| `npm run test:run` | 執行所有測試（一次性） |
| `npm run test:coverage` | 執行測試並產生覆蓋率報告至 `coverage/`（不納入 git） |
