# 🎈 數字氣球 BalloonPop

> 按照 1、2、3 的順序戳氣球，學習數字序列

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 3~5 歲 |
| 路徑 | `/balloon-pop` |
| 原始碼 | `src/games/BalloonPop/BalloonPop.jsx` |
| 學習目標 | 數字序列、手眼協調 |

## 遊戲規則

1. 畫面上有 7 顆彩色氣球，分別標記 1~7
2. 氣球隨機散佈在天空中並上下浮動
3. 按照 **從小到大** 的順序戳破氣球（先戳 1，再戳 2...）
4. 戳對了氣球會爆破（💥），戳錯則搖晃提示
5. 依序戳完所有氣球即過關

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 3 次 |
| ⭐ | 失誤 > 3 次 |

## 介面元素

- **下一個提示** — 顯示目前應戳的數字
- **進度計數** — 已戳 / 總數（如 `✅ 3/7`）
- **背景雲朵** — 裝飾性動畫雲朵 ☁️

## 技術細節

- 氣球使用 **網格佈局 + 隨機偏移** 生成位置，避免重疊
- 每顆氣球有不同顏色、大小、動畫延遲，製造自然浮動感
- 錯誤戳擊觸發 CSS `shake` 動畫
- 戳破效果：氣球消失 + 💥 爆破 emoji
- 10 種氣球顏色循環使用
