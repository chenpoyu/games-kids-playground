# 🎨 顏色配對 ColorMatch

> 翻開卡片找出相同顏色，訓練記憶力與顏色辨識能力

## 基本資訊

| 項目 | 內容 |
|------|------|
| 適齡 | 2~4 歲 |
| 路徑 | `/color-match` |
| 原始碼 | `src/games/ColorMatch/ColorMatch.jsx` |
| 學習目標 | 記憶力、顏色辨識 |

## 遊戲規則

1. 畫面上顯示數張倒蓋的卡片
2. 點擊卡片翻開，看到顏色
3. 翻開第二張，若兩張顏色相同則配對成功
4. 配對失敗會自動蓋回
5. 找出所有配對即過關

## 星星評分

| 星星 | 條件 |
|------|------|
| ⭐⭐⭐ | 零失誤 |
| ⭐⭐ | 失誤 ≤ 2 次 |
| ⭐ | 失誤 > 2 次 |

## 技術細節

- 卡片隨機洗牌，每次遊玩配置不同
- 翻牌使用 CSS 3D transform 動畫
- 配對成功的卡片保持翻開並顯示標記
- 每次翻開計為一次嘗試 (attempt)
