# ㄅ 注音符號

> 路徑：`/zhuyin-learn` | 元件：`src/games/ZhuyinLearn/ZhuyinLearn.jsx`

## 遊戲概述

**注音符號**是一款專為 4~6 歲幼兒設計的中文注音學習遊戲，涵蓋全部 37 個注音符號（ㄅ～ㄩ），提供三種學習模式幫助小朋友認識台灣正體中文的注音系統。

| 項目 | 內容 |
|------|------|
| 適齡 | 4~6 歲 |
| 路徑 | `/zhuyin-learn` |
| 解鎖條件 | ABC 英文字母初級 2 星 |
| 核心能力 | 注音符號認識、配對、順序 |

## 遊戲模式

### 📖 認識注音 (learn)
以大卡片逐一瀏覽 37 個注音符號：
- 顯示大型注音符號、對應 emoji 圖示、例字（如 ㄅ → 爸爸 👨）
- 🔊 點擊喇叭按鈕可朗讀例字
- 進入時自動語音朗讀當前例字
- 提供上一個 / 下一個導覽按鈕

### 🎯 注音配對 (match)
看圖片與例字，從 4 個選項中找出正確的注音符號：
- 每題隨機從符號池抽取，避免重複
- 正確：上升音階 + 綠色高亮
- 錯誤：低沉音效 + 搖晃動畫

### 🔤 注音排序 (order)
從打亂的注音符號中，按照正確的注音順序依序點選：
- 隨機選取連續一段注音符號後打亂
- 已排入的符號顯示於上方
- 全部排完即得分

## 注音資料

涵蓋全部 37 個注音符號，每個符號配有：
- 拼音對照（b, p, m, f, d, t, n, l...）
- 例字（如：飛機、媽媽、大象）
- 對應 emoji
